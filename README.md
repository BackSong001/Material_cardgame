# Material Classifier

Windows 10·11 x64에서 [게임 실행 파일](dist/MaterialClassifier.exe)을 실행하세요. 보드에서 그래프 하나를 골라 확대하고 피크 파장을 읽은 뒤 **정답 보기**를 누르세요. 보드로 돌아가면 다른 카드도 자유롭게 고를 수 있습니다. Tab과 Space로도 조작할 수 있습니다.

기본 배포판에는 모의 스펙트럼 20장이 들어 있습니다. 인터넷이나 Excel 설치 없이 동작합니다. 실제 엑셀로 제작하려면 [기술 설계](TRD.md)를 참고하세요.
